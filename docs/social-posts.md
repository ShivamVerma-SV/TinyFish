## LinkedIn

I built **RoleCurrent** for the TinyFish × TechnoJam bounty — an evidence-first job discovery product designed to replace endless job-board scrolling with a concise, live shortlist.

RoleCurrent uses TinyFish Search to discover individual openings across multiple ATS sources, TinyFish Fetch to read and verify the actual listing pages, and an optional TinyFish Agent fallback for difficult dynamic pages. It then removes duplicates, filters and ranks roles against editable preferences, and links directly to the original application page.

The interface reports source failures honestly, preserves successful results when one source fails, and clearly distinguishes verified listings from search-only discoveries. No invented jobs, fake metrics, or generic career-homepage links.

Built with React, TypeScript, FastAPI, and TinyFish.

**Live opportunities. Less searching.**
